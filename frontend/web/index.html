插件下载

🧩
言外插件

Chrome / Edge（MV3），在真实知乎页面上划词解析。

下载

下载解压后，打开 chrome://extensions → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择解压出的目录。

1
安装插件

下载插件包，在 Chrome 里「加载已解压的扩展程序」。

2
知乎划词

打开任意知乎页面，选中看不懂的文字（≥4 字）。

3
看解析

气泡弹出，一句话人话先到，再展开言外之意，附证据出处。
